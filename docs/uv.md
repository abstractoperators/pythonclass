step by step basic command for uv and pip
1. Install uv:
- irm https://astral.sh/uv/install.ps1 | iex
- uv --version (check if it is installed)

Install PIP:
- https://bootstrap.pypa.io/get-pip.py - link to install
- python get-pip.py 
- pip --version

2. Run the command  uv run python for the create environment
3. .venv\Scripts\Activate.ps1 - activate the environment
4. Install Jupyter - pip install notebook
5. jupyter notebook - to open on local host


using uv to install jupyter:
- uv pip install notebook
jupyter notebook - to open on local host
